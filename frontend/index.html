PROJECT METHODOLOGY

How CardioAI Works

A complete machine learning workflow from raw data to model-based inference.

01

Data Collection

The project uses a structured heart disease dataset containing clinical and demographic patient attributes.

02

Data Preparation

The dataset is loaded, checked for missing values and prepared for machine learning.

03

Feature Processing

The 13 independent variables are used as inputs to the classification pipeline.

04

Random Forest

A Random Forest classifier is trained using a stratified train-test split.

05

Evaluation

Accuracy, precision, recall, F1 score and confusion matrix are used to evaluate performance.

06

Inference

New patient attributes are passed through the trained pipeline to obtain a prediction.
