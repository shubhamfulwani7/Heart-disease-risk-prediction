# Heart Disease Case Study

## Overview

This project presents a data science case study based on a heart disease dataset.

The project covers:

- Data analysis
- Data preprocessing
- Exploratory data analysis
- Feature analysis
- Machine learning
- Model evaluation
- Web application development
- Vercel deployment

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML
- CSS
- JavaScript
- Vercel
